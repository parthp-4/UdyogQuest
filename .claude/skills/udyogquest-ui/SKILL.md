# UdyogQuest UI

Keep pages information-dense but calm. Preserve a coherent spacing, type, border, and color system. Use existing local primitives and icon libraries before creating new components.

Every control needs a clear outcome: navigation, drawer/modal, upload, search, filter, sort, expand, download, or workflow transition. Keep content inside stable layout bounds; wrap long labels and test narrow viewports. Avoid overlapping hero text, nested decorative cards, and placeholder states.

For journey/timeline work, prefer the shared dependency model and React Flow interactions over duplicated visual-only data. Make status, dependency type, and selected state visually distinct and explainable.
